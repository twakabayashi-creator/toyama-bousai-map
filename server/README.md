# 集計サーバー（サンプル）

協賛スポットの「見た回数・来店チェックイン数・クーポン使用数・サイトを開いた数」を数えるサーバーです。
アプリ本体の公開も、このサーバー1つで兼ねられます。

## 必要なもの
- Node.js 18 以上（追加のインストールは不要）

## 起動のしかた
リポジトリのいちばん上のフォルダーで、次のように起動します。

```
REPORT_PASSWORD=好きなパスワード PORT=8080 node server/server.js
```

| 設定（環境変数） | 内容 |
|---|---|
| `REPORT_PASSWORD` | レポート画面のパスワード（必須） |
| `PORT` | 待ち受けるポート（初期値 8080） |
| `DATA_FILE` | 集計を保存するファイル（初期値 `server/data/counts.json`） |
| `ALLOWED_ORIGIN` | アプリを別のドメインに置く場合、そのURL（例 `https://app.example.jp`） |
| `TRUST_PROXY` | Nginx などをこのサーバーの前に置き、そこで送信元（X-Forwarded-For）を付け直している場合だけ `1`。それ以外は設定しない |
| `HSTS` | HTTPS で公開している場合に `1` |

本番では、Nginx などで HTTPS（https://〜）にしてください。スマホの位置情報は HTTPS でないと使えません。

## 安全のための仕組み
- `sponsors.csv` にある番号の協賛店の回数だけを受け付けます（CSVは5分ごとに読み直します）
- 同じ送信元からの送信は1分に60回まで
- レポートのパスワードを5回まちがえると、その送信元を15分受け付けません。パスワードは12文字以上にしてください
- 壊れたURLや想定外のエラーでサーバーが止まらないようにしています
- 安全用のヘッダー（CSP、X-Frame-Options など）を付けています
- 回数の水増しを**完全に**防ぐことはできません。協賛企業へのレポートは「目安」として扱ってください

## アプリ側の設定
`config.js` の `ANALYTICS_ENDPOINT` に、このサーバーのURLを書きます。

- アプリもこのサーバーで公開する場合：`const ANALYTICS_ENDPOINT = "/api/event";`
- アプリを別の場所に置く場合：`const ANALYTICS_ENDPOINT = "https://集計サーバーのドメイン/api/event";`（サーバー側に `ALLOWED_ORIGIN` も設定）

## レポートの見かた
ブラウザで `https://サーバーのドメイン/report` を開き、パスワードと期間を入れて「表示する」を押します。
協賛スポットごとの合計が表で出ます。「CSVでダウンロード」で日別の明細を保存できます。

## 集める情報
回数だけです。名前・位置情報・端末IDなど、個人を特定できる情報は受け取りません（`privacy.html` 参照）。
集計は `DATA_FILE` に「日付 × 協賛スポット番号 × 種類」の合計数として保存されます。定期的にバックアップしてください。
