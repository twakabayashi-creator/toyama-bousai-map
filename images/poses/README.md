# キャラクターのポーズ素材

社内オリジナルキャラクター（しっぽがプラグのクマ）の、背景を透明にした素材です。
front / stand-side / tools / side / sleep は、元のPDFから高解像度で切り出しています。
surprise / question / happy-tools / peek / sad / screwdriver / sit / back / eat / plug-on / walk-side / run / sit-side / banzai / power / stand は、いただいた画像（約200ピクセル）をそのまま保存しています。

| ファイル | ポーズ |
|---|---|
| `front.png` | 正面を向いて立つ（現在地の `images/character.gif` はこのポーズから作成） |
| `stand-side.png` | 少し横を向いて立つ |
| `tools.png` | スパナとボルトを持って歩く |
| `side.png` | 横（左）を向く |
| `sleep.png` | 寝ている |
| `surprise.png` | びっくり（吹き出しに「！」） |
| `question.png` | ふしぎそうに見上げる（吹き出しに「？」） |
| `happy-tools.png` | ドライバーとスパナを持ってにっこり |
| `peek.png` | 壁からのぞく |
| `sad.png` | しょんぼり |
| `screwdriver.png` | ドライバーを持って横向きに歩く |
| `sit.png` | 正面を向いて座る |
| `back.png` | 後ろ姿 |
| `eat.png` | 座って食べる |
| `plug-on.png` | プラグをコンセントに差す（ON） |
| `walk-side.png` | 横向きに歩く |
| `run.png` | 正面を向いて元気に走る |
| `sit-side.png` | 横向きに座る |
| `banzai.png` | バンザイ（目が「＞＜」） |
| `power.png` | 力こぶ（後ろが光る） |
| `stand.png` | 正面でまっすぐ立つ |

アプリの画面ではまだ使っていません（現在地のキャラクターは `images/character.gif`）。
