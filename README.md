# とやま防災めぐり（GPS版）

富山県のハザードマップ上の防災ポイントを巡って、楽しく防災を学ぶWebアプリです。

- クイズに正解するとスタンプ（100pt）
- 「避難場所さがしミッション」で、災害の種類に合った避難場所を地図から見つける（50pt）
- 実際にその場所へ行くと「現地チェックイン」で金のスタンプ（100pt）
- 現在地から近くの避難場所を、災害の種類ごとに探せる

スマホのブラウザでURLを開くだけで使えます。ホーム画面に追加すると、アプリのように起動できます。

## ファイルの説明

| ファイル | 中身 | 編集のしやすさ |
|---|---|---|
| `spots.csv` | 防災ポイント・説明文・クイズ（Excelで編集） | ★ ここだけ編集すればOK |
| `app.js` | アプリの動き | 触らなくてOK |
| `style.css` | 見た目（色・文字の大きさ） | 触らなくてOK |
| `index.html` | 画面の骨組み・出典表示 | 触らなくてOK |
| `data/shelters.json` | 指定緊急避難場所（1,435か所） | データ更新時のみ |
| `data/volcano.json` | 弥陀ヶ原火山ハザードマップ | データ更新時のみ |
| `sw.js` | 電波が弱くても開けるようにする仕組み | `spots.csv` 以外を変えたら `VERSION` を1つ増やす |

## 防災ポイントを追加・変更したいとき（CSV）

防災ポイントは `spots.csv` で管理しています。Excelで開いて編集できます。

### 手順
1. GitHubの `spots.csv` を開き、右上の「…」→「Download」でダウンロード
2. Excelで開いて編集し、保存（「CSV UTF-8」でも、ふつうの「CSV」でもOK）
3. GitHubのリポジトリのトップで「Add file」→「Upload files」を押し、編集した `spots.csv` をドラッグ＆ドロップ
   （ファイル名は必ず `spots.csv` のままにしてください。同じ名前のファイルが上書きされます）
4. 「Commit changes」を押す
5. 1〜3分後にアプリを開き直すと反映されます

### 列の説明

| 列 | 必須 | 書き方 |
|---|---|---|
| 番号 | | 1, 2, 3 …（スタンプの記録に使います。一度決めた番号は変えないのがおすすめ） |
| 名前 | ★ | ポイントの名前 |
| 場所 | | 市町村名など |
| 緯度 | ★ | 例：36.7013（Googleマップで場所を右クリックすると、最初に出る数字） |
| 経度 | ★ | 例：137.2133（同じく2番目の数字） |
| 災害の種類 | | 表示用の文字。例：洪水、津波、そなえ |
| ミッション | | 避難場所さがしの種類：「洪水」「崖崩れ」「地震」「津波」のどれか。空欄ならミッションなし |
| 説明1〜説明3 | | 説明文。使わない列は空欄でOK |
| 問題 | ★ | クイズの問題 |
| 正解 | ★ | 正しい答え |
| 不正解1〜不正解3 | ★ | まちがいの選択肢。最低1つ。表示順は自動でシャッフルされます |
| 解説 | | 正解したあとに出る説明 |

- 行を消すとポイントがなくなり、行を足すとポイントが増えます（いくつでもOK）
- 入力ミスがある行は地図に表示されず、アプリの画面に「何行目のどこがおかしいか」が出ます
- 緯度と経度を逆に書いた場合も教えてくれます

## データの出典

- 背景地図・洪水・津波・土砂災害：国土地理院（地理院タイル／ハザードマップポータルサイト）
- 指定緊急避難場所・弥陀ヶ原火山ハザードマップ：富山データ連携基盤（富山県）
  https://publicsite.tdcp.pref.toyama.jp/toyama16000/panel/1747374412481
  （2026年11月16日取得・加工）

## 注意

- このアプリは学習用です。災害時は市町村の避難情報とハザードマップを必ず確認してください。
- 位置情報はスマホの中だけで使い、どこにも送信しません。記録もスマホの中だけに保存されます。
